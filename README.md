# Portfolio Project

This project is a personal portfolio website showcasing my skills, projects, and experience.

## Technologies Used

- **HTML5**: For structuring the content of the website.
- **CSS3**: For styling the website and making it visually appealing.
- **React**: A JavaScript library for building interactive and dynamic user interfaces.
- **Chakra UI**: A simple, modular, and accessible component library for React.
- **Framer Motion**: A library for animations and gestures in React.
- **Git**: Version control system for tracking changes and collaboration.
- **GitHub**: Hosting the repository and managing version control.
- **Webpack**: Module bundler to bundle JavaScript files for usage in a browser.
- **Babel**: JavaScript compiler to convert ES6+ code into a backwards-compatible version of JavaScript.

## Features

- Responsive design
- Interactive UI components
- Dynamic project showcase
- Contact form with validation
- Smooth animations using Framer Motion
